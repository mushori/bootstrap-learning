# 🚀 Simple Bootstrap Admin Dashboard & Login

Project ini adalah template antarmuka web responsif yang menggabungkan halaman **Login** dan **Admin Dashboard** dalam satu file HTML. Dibangun menggunakan **Bootstrap 5**, project ini mensimulasikan alur autentikasi sederhana menggunakan JavaScript dan `SessionStorage` tanpa perlu reload halaman (SPA-like experience).

Cocok digunakan sebagai starter kit untuk tugas kuliah, prototipe aplikasi, atau belajar layouting Bootstrap.

## ✨ Fitur Utama
* **Responsive Design:** Tampilan rapi di mobile, tablet, dan desktop menggunakan Grid System Bootstrap.
* **SPA Simulation:** Perpindahan mulus antara halaman Login dan Dashboard menggunakan Vanilla JavaScript (DOM Manipulation).
* **Session Persistence:** Status login disimpan sementara menggunakan `sessionStorage` (data tidak hilang saat di-refresh).
* **Modern UI Components:**
    * Clean Login Form.
    * Sidebar Navigation (Collapsible).
    * Interactive Cards & Statistics.
    * Responsive Data Tables.
    * Bootstrap Icons integration.

## 🛠️ Tech Stack
Project ini dibangun dengan teknologi standar web modern:
* **HTML5** - Struktur semantik.
* **CSS3** - Styling custom & layout.
* **Bootstrap 5.3.2** - Framework CSS untuk responsivitas dan komponen UI.
* **Bootstrap Icons** - Ikon vektor berkualitas.
* **JavaScript (ES6)** - Logika interaksi antarmuka dan manajemen state sesi.
